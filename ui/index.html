    Algorithms & Data Structures Used

    The system is written strictly in pure standard C (C11) without third-party dependencies or language runtime libraries.

    DATA STRUCTURE

    Hash Table (Separate Chaining)

    Employs the djb2 hashing algorithm with separate chaining for collision resolution. Used to store document vocabulary, track word frequencies in $O(1)$ expected time, and compute the word-level Jaccard similarity index.

    STRING MATCHING

    Knuth-Morris-Pratt (KMP)

    Constructs a Longest Prefix Suffix (LPS) $\pi$-table for candidate phrase patterns. Bypasses redundant character comparisons to achieve guaranteed $O(N + M)$ worst-case phrase search across text streams.

    STRING MATCHING

    Rabin-Karp Algorithm

    Computes rolling polynomial hashes modulo $10^9 + 7$ with base 256. Accelerates continuous substring searches by transitioning hash windows in $O(1)$ amortized time with verification checks.

    SORTING

    Merge Sort

    A recursive divide-and-conquer sorting algorithm implemented manually without qsort(). Orders candidate documents by similarity percentage in stable $O(D \log D)$ time.

    DATA STRUCTURE

    Dynamic Arrays

    Contiguously allocated memory buffers (TokenArray, SentenceArray, MatchArray, PhraseMatchArray, RankedDocumentArray) featuring geometric $2\times$ capacity growth and leak-safe reallocation.

    SEARCHING

    Linear & Threshold Search

    Provides fast sequential and criteria-based searching across ranked document arrays, enabling filtering by document filename and minimum similarity threshold ($\ge X\%$).

    Project Information & Technical Specifications

    Problem Statement

    Academic institutions and software organizations face significant challenges in identifying content duplication and text recycling. Existing cloud solutions often rely on opaque black-box APIs or heavyweight external runtimes. This system provides a transparent, deterministic plagiarism detection engine written in standard C demonstrating foundational algorithms, optimal time/space complexity, and rigorous memory safety.

    Similarity Calculation Formula

    $$\text{Overall Similarity} = 0.30 \times \text{Word Jaccard} + 0.30 \times \text{Sentence Jaccard} + 0.40 \times \text{Phrase Coverage}$$

    Academic Limitations & Disclaimers

    Important Notice: This system performs lexical and textual similarity analysis based on exact vocabulary, sentence Jaccard overlap, and continuous n-gram matching. Semantic paraphrasing using extensive synonym substitution or structural restructuring without shared n-grams may not be detected reliably. This software assists human evaluators and does not establish intentional plagiarism.
