    ARCHITECTURE & DSA SPECIFICATIONS

    Technical Specifications & Academic Limits

    Deterministic algorithms, linguistic heuristic foundations, and institutional use policies.

    Plagiarism Detection Algorithms (C11 DSA Engine)

    The plagiarism comparison engine is implemented in native standard C (C11) for deterministic efficiency, bounded memory utilization, and speed:

    DATA STRUCTURE

    Hash Table (Separate Chaining)

    Computes word frequency histograms using the djb2 hash function with linked-list separate chaining. Evaluates word Jaccard similarity in $O(W)$ time.

    Time: $O(W)$ • Space: $O(W)$
    STRING MATCHING

    Knuth-Morris-Pratt (KMP)

    Constructs a $\pi$-table of Longest Proper Prefix which is also a Suffix (LPS) to execute linear $O(N + M)$ phrase search without redundant backtracking.

    Time: $O(N + M)$ • Space: $O(M)$
    ROLLING HASH

    Rabin-Karp String Matcher

    Computes rolling polynomial hashes modulo $10^9 + 7$ with base 256. Accelerates continuous matching n-gram discovery in $O(1)$ amortized time per window.

    Time: $O(N + M)$ avg • Space: $O(1)$
    SORTING

    Recursive Merge Sort

    Stable divide-and-conquer sorting algorithm ordering reference documents by similarity percentage in guaranteed $O(D \log D)$ time without standard qsort().

    Time: $O(D \log D)$ • Space: $O(D)$

    Mathematical Similarity Formula

    The composite similarity index is calculated as a weighted combination of three distinct algorithmic metrics:

    Overall Similarity = 0.30 × Word_Jaccard + 0.30 × Sentence_Jaccard + 0.40 × Phrase_Coverage

    AI Writing Pattern Heuristics

    AI detection is an unfitted heuristic triage engine evaluating statistical uniformity across three tiers:

    • Stylometry: Moving Average Type-Token Ratio (MATTR), sentence length variation (CV), repeated trigram ratios, and punctuation entropy.
    • Unicode Forensics: Detection of zero-width characters, exotic spacing markers, Cyrillic/Greek homoglyph replacements, and typographic quote distributions.
    • Discourse Patterns: Detection of rule-of-three structures (tricolons), negation pivots ("It's not X, but Y"), self-Q&A formulations, and paragraph length uniformity.

    Institutional Limitations & Disclaimers

    • Sample Floor: Texts with fewer than 150 words receive an explicit Insufficient Evidence classification to avoid statistical false positives.
    • Domain Terminology: Highly technical or legal prose can naturally exhibit elevated regularity.
    • Corpus Dependency: Plagiarism comparison depends solely on documents available in the local repository; web indexing is not performed.
    Mandatory Institutional Policy: Plagiarism Detection System is an investigative aid for human evaluators. Scores represent statistical regularity and local corpus overlap, not scientific certainty or legal proof of authorship. Never use this application as the sole basis for academic integrity or disciplinary proceedings.
